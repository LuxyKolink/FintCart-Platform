# Publishing platforms with interactive/computational content

Observable — probably the closest to what you're describing. It's a notebook-style publishing platform where posts can contain live JavaScript cells, charts, and calculations that readers can interact with and modify.
Quarto — an open-source scientific publishing system that lets you embed executable code (R, Python, Julia) inside documents/posts. Readers can see live outputs, though interactivity depends on hosting setup.
Distill for R Markdown / Distill.pub — used heavily in ML research for articles with interactive diagrams and visualizations baked into the post.
Jupyter Notebooks + nbconvert/Voilà — notebooks can be published as interactive web pages where readers run or tweak calculations.
Substack / Ghost — these are more traditional publishing platforms, but people sometimes embed interactive content via iframes (e.g., from Observable or CodePen).
Notion — supports some embeds but is fairly limited on the interactive/computational side.

More niche / experimental

Curvenote — built specifically for scientific writing with interactive figures and reusable computational content.
Idyll — an open-source markup language designed exactly for this: explanatory, interactive articles (think "explorable explanations").
