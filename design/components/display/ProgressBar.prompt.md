The platform's signature progress motif — marigold fill showing accumulated learning points.

```jsx
<ProgressBar value={680} max={1000} label="Progreso" showValue />
<ProgressBar value={40} tone="var(--success)" size="sm" />
```

Default fill is marigold (`--brand-accent`). Use `showValue` for the "value/max" readout next to the label.
