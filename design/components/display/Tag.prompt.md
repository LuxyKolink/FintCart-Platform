Category chip with a colored dot — the catalog's topic-filter vocabulary. Color with the `--cat-*` tokens.

```jsx
<Tag color="var(--cat-ahorro)" active>Ahorro</Tag>
<Tag color="var(--cat-credito)">Crédito</Tag>
<Tag color="var(--cat-inversion)">Inversión</Tag>
```

`active` underlines with the category color. Renders as `<a>` when `href` is set, otherwise a button.
