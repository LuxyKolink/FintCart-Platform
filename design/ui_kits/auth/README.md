# UI Kit — Autenticación

Acceso a FintCart: **login**, **registro** y **verificación de correo** (código de 6 dígitos),
más estado de éxito. Panel de marca a la izquierda (degradado coral→púrpura) + formulario a la
derecha. Refleja OAuth2 + PKCE y el consentimiento de datos (Ley 1581).

**Archivos:** `index.html`, `App.jsx`. Compone `Input`, `Checkbox`, `Button`, `Badge`.
El flujo navega login → registro → verificación → éxito → catálogo.
